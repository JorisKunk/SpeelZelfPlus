# SpeelZelf+

SpeelZelf+ is een digitale ontwerpmethode, aangeboden als statische webapplicatie, voor welzijnsmedewerkers die bestaande beweegspellen willen aanpassen zodat bewoners deze zonder continue begeleiding van een medewerker kunnen starten en spelen.

## Bestanden
- `index.html`
- `speelzelfplus.css`
- `speelzelfplus.js`
- `assets/images/` — voeg hier de illustraties toe die in `speelzelfplus.js` worden genoemd.

## Werkwijze
1. Vul een bestaand beweegspel in.
2. Laat bewoners het oorspronkelijke spel eerst proberen en observeer wat zelfstandig lukt.
3. Doorloop tien ontwerpdoelen en kies passende aanpassingen, een eigen oplossing, `Geen aanpassing nodig` of `Nog beoordelen met bewoners`.
4. Gebruik het automatisch opgebouwde SpeelZelf+ plan voor uitvoering.
5. Test het aangepaste spel eerst direct met bewoners en daarna gedurende meerdere gewone momenten in de dagelijkse omgeving.
6. Druk het plan af of sla het via de browser op als PDF.

De applicatie gebruikt alleen HTML, CSS en JavaScript en bewaart tussentijdse keuzes lokaal in de browser.
